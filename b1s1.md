### ¿Cuál tiene la sintaxis más fácil de comprender?

En mi opinión, la sintaxis más fácil es la de Python, porque es la más corta y se lee casi como lenguaje natural, sin necesidad de declarar tipos ni hacer conversiones explícitas. Scala 3 me parece un punto intermedio: es claro y conciso, pero exige indicar tipos y convertir a Double. Java por otro lado, tiene una sintaxis compleja que requiere saber que tipo de dato estás usando, saber declararlo, usar identacion adecuada y manejar el uso de funciones correctamente.

En las versiones funcionales (Haskell, Python y Scala 3) desaparecen el bucle y la variable mutable. En Python y Haskell se usa `sum`, que recibe la lista completa y devuelve la suma; en Scala se usa `foldLeft`, que parte de 0 y va acumulando cada elemento. Luego se divide entre el tamaño de la lista. Aquí se describe qué se quiere calcular, no cómo recorrer la lista.

## Ejercicio final

### Parte 1: de Java a Scala

Código original (Java, imperativo):

```java
double getAverage(List<Integer> nums) {
	var sum = 0;
	for(var num : nums) {
		sum += num;
	}
	return sum / (double)nums.size();
}
```

Mi traducción a Scala 3:

```scala
def getAverage(nums: List[Int]): Double =
  if nums.isEmpty then 0.0 else nums.sum.toDouble / nums.size
```

Prueba en `scala-cli repl`:

```scala

```

### Comparación (imperativo vs. funcional)

La versión imperativa en Java usa una variable mutable (sum) y un bucle for que va modificando esa variable paso a paso. Hay que decirle a la computadora cómo calcular el resultado, y el estado cambia en cada iteración.

En las versiones funcionales (Haskell, Python y Scala 3) desaparecen el bucle y la variable mutable. Se usa una función como sum, que recibe la lista completa y devuelve el resultado, y luego se divide entre el tamaño de la lista. Aquí se describe qué se quiere calcular, no cómo recorrer la lista.

Ventajas de la versión funcional: el código es más corto, más fácil de leer, no tiene estado mutable (menos posibilidad de errores) y la función siempre da el mismo resultado para la misma entrada.

La versión imperativa tiene más control paso a paso, pero necesita más líneas y más variables para hacer lo mismo.
